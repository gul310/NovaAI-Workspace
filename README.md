## 📖 Overview

NovaAI Workspace is a modern AI-powered SaaS website developed as part of the DecodeLabs Full Stack Development Industrial Training Program.

The project demonstrates modern frontend development practices including responsive design, semantic HTML, CSS architecture, and interactive JavaScript components. Future milestones will extend this project into a complete full-stack application with backend APIs and database integration.
